# Chess Kids

אתר שחמט בעברית — גרסת אבטיפוס ראשונה.

## מה כבר עובד
- לוח שחמט אינטראקטיבי עם מהלכים חוקיים לפי חוקי השחמט.
- משחק מקומי לשני שחקנים על אותו מחשב.
- מצב נגד מחשב עם בחירת מהלך חוקי אקראי (עדיין לא Stockfish).
- החלפת צדדים, הצגת היסטוריית מהלכים וערכת נושא בהירה/כהה.
- התאמה למסכים קטנים.

## הפעלה
אפשר לפתוח את `index.html` בדפדפן. נדרש חיבור לאינטרנט לטעינת ספריית chess.js מ-CDN.

## מה עדיין לא קיים
אין עדיין שרת, חשבונות משתמשים, שמירת משחקים, משחקים מקוונים, שעונים, דירוג ELO, פאזלים, Stockfish או אפליקציית Windows. אלה שלבי הפיתוח הבאים; אין לראות בגרסה זו מוצר מלא.
