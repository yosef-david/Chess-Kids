# Supabase — הכנת בסיס הנתונים של Chess Kids

קובץ הסכימה נמצא ב-`schema.sql`.

## הקמה
1. יוצרים פרויקט Supabase חדש.
2. פותחים את SQL Editor בפרויקט.
3. מעתיקים אליו את כל התוכן של `schema.sql) ומריצים.
4. בודקים שנוצרו הטבלאות: profiles, games, game_moves, friendships, puzzles.

## מפתחות
כדי לחבר את האתר נדרשים Project URL ומפתח publishable/anon ציבורי. אין לשלוח או להכניס לאתר את מפתח `service_role` או סיסמת מסד הנתונים — אלה סודות שרת.

## מצב החיבור
הסכימה והגדרות ההרשאות מוכנות במאגר, אך האתר עדיין לא מחובר לפרויקט Supabase. לאחר יצירת הפרויקט יהיה צורך להגדיר את כתובת הפרויקט והמפתח הציבורי, ולחבר את מסכי ההרשמה, ההתחברות והמשחקים.
