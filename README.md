# Chess Kids

אתר שחמט בעברית (RTL), עם ממשק כהה ובהיר.

## מה נמצא כרגע במאגר
- לוח שחמט אינטראקטיבי וחוקי שחמט באמצעות chess.js.
- משחק מקומי לשני שחקנים.
- משחק נגד Stockfish 19 Lite בדפדפן, באמצעות Web Worker.
- שעוני משחק: דקה, 3, 5 ו-10 דקות.
- ביטול מהלך במשחק מקומי, היסטוריית מהלכים וייבוא/ייצוא PGN.
- החלפת צדדים וערכת נושא בהירה/כהה.
- מסכי הרשמה והתחברות מוכנים לחיבור Supabase.
- שלד SQL לפרופילים, משחקים, מהלכים, חברויות, חידות ותור למציאת יריב.
- שמירת מהלכים אונליין דרך פונקציות SQL ובקרת תור בסיסית.

## הפעלה מקומית
נדרשת התקנת Node.js:

```bash
npm install
npm run dev
```

## בנייה
```bash
npm run build
```

## פרסום ב-Vercel
ייבא את המאגר `yosef-david/Chess-Kids` ל-Vercel. הגדרות הבנייה כבר נמצאות ב-`vercel.json`:
- Build command: `npm run build`
- Output directory: `dist`

קובץ `vercel.json` גם מנתב את קובצי Stockfish דרך כתובת האתר כדי שהדפדפן יוכל לטעון אותם כ-Web Worker. עדיין לא בוצעה פריסה בחשבון Vercel, ולכן אין כתובת אתר פעילה מצד הפרויקט.

## חיבור Supabase
1. צור פרויקט Supabase.
2. פעל לפי ההוראות ב-`supabase/README.md` והריץ את `supabase/schema.sql` ב-SQL Editor.
3. העתק את Project URL ואת המפתח הציבורי (Publishable או anon) אל `config.js`.
4. פרסם מחדש את האתר.

לעולם אין להכניס ל-`config.js` מפתח `service_role` או סיסמת מסד נתונים. הקובץ נשלח לדפדפן והוא ציבורי.

## מה עדיין דורש השלמה ובדיקות
- סנכרון שעוני אונליין בצד השרת ואכיפת timeout.
- אימות חוקיות מהלכים בצד השרת; כרגע הלקוח בודק חוקיות והשרת בודק זהות, תור וסדר מהלכים.
- עדכון דירוג ELO אמיתי, פרופילים מלאים, היסטוריית משחקים ופאזלים.
- ניהול חברים, הזמנות למשחק פרטי, צ'אט בטוח וממשק ניהול.
- אפליקציית Windows (Electron).
- בדיקות בפועל לאחר הגדרת Supabase ופריסה ב-Vercel.
