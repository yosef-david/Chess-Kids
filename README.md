# Chess Kids

אתר שחמט בעברית (RTL), עם ממשק כהה ובהיר.

## מה נמצא כרגע במאגר
- לוח שחמט אינטראקטיבי עם חוקי שחמט באמצעות chess.js.
- משחק מקומי לשני שחקנים.
- משחק נגד Stockfish 19 Lite בדפדפן, באמצעות Web Worker.
- שעוני משחק: דקה, 3, 5 ו-10 דקות.
- ביטול מהלך במשחק מקומי, היסטוריית מהלכים וייבוא/ייצוא PGN.
- חידת מט במהלך אחד.
- החלפת צדדים וערכת נושא בהירה/כהה.
- מסכי הרשמה והתחברות באמצעות Supabase Auth.
- תור למציאת יריב, משחק פרטי עם קוד הזמנה ועדכוני מהלכים בזמן אמת, לאחר חיבור Supabase.
- עדכון דירוג ELO לאחר משחק אונליין שהסתיים.
- לוח ניהול למנהלים לצפייה בשחקנים ובמשחקים ולעדכון דירוגים.
- פרופיל שחקן שניתן לעריכה, טבלת דירוגים והיסטוריית משחקים שמורים.
- סכימת SQL לפרופילים, משחקים, מהלכים, חברויות, חידות ותור למציאת יריב.
- שלד אפליקציית Windows באמצעות Electron.

## הפעלה מקומית
נדרשת התקנת Node.js:

```bash
npm install
npm run dev
```

## בנייה לאתר
```bash
npm run build
```

הפקודה מעתיקה את קובצי Stockfish לתיקיית `public/engine` ואז בונה את האתר ל-`dist`.

## פרסום ב-Vercel
ייבא את המאגר `yosef-david/Chess-Kids` ל-Vercel. הגדרות הבנייה נמצאות ב-`vercel.json`:
- Build command: `npm run build`
- Output directory: `dist`

עדיין לא בוצעה פריסה בחשבון Vercel, ולכן אין כתובת אתר פעילה מצד הפרויקט.

## חיבור Supabase
1. צור פרויקט Supabase.
2. פעל לפי ההוראות ב-`supabase/README.md` והריץ את `supabase/schema.sql` ב-SQL Editor.
3. העתק את Project URL ואת המפתח הציבורי (Publishable או anon) אל `config.js`.
4. הגדר כתובת אתר וכתובת Redirect ב-Supabase Auth.
5. עדכן את `project_id` בקובץ `supabase/config.toml`.
6. פרוס את פונקציית אימות המהלכים:
   ```bash
   supabase link --project-ref YOUR_PROJECT_REF
   supabase functions deploy submit-move
   ```
7. פרסם מחדש את האתר.

לעולם אין להכניס ל-`config.js` מפתח `service_role` או סיסמת מסד נתונים. הקובץ נשלח לדפדפן והוא ציבורי.

## אפליקציית Windows
ליצירת מתקין Windows (NSIS) במחשב Windows:

```bash
npm install
npm run desktop:dist
```

המתקין ייווצר בתיקיית `release`. להפעלה מקומית בחלון Electron:

```bash
npm run desktop
```

כדי שהאפליקציה תטען את האתר שכבר פורסם, אפשר להגדיר משתנה סביבה בשם `CHESS_KIDS_URL` עם כתובת האתר לפני ההפעלה. ללא המשתנה, היא תפתח את הגרסה המקומית שנבנתה בתיקיית `dist`.

## מה עדיין דורש השלמה ובדיקות
- בדיקות בפועל של שעוני השרת, timeout והתנהגות בזמן ניתוק.
- בדיקות בפועל של אימות מהלכים בצד השרת, שעוני השרת, timeout והתנהגות בזמן ניתוק.
- פרופילים מורחבים, רשימת חברים, צ'אט בטוח ופאזלים נוספים.
- רשימת חברים, צ'אט בטוח והרחבת כלי הניהול.
- בדיקות בפועל לאחר הגדרת Supabase ופריסה ב-Vercel.
- בניית מתקין Windows ובדיקתו על מחשב Windows.
