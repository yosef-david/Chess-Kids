# Chess Kids

אתר שחמט בעברית, בכיוון RTL.

## גרסה נוכחית
- לוח שחמט אינטראקטיבי.
- משחק מקומי לשני שחקנים.
- מצב נגד מחשב בסיסי שבוחר מהלך חוקי אקראי.
- החלפת צדדים, היסטוריית מהלכים וערכת נושא בהירה/כהה.
- תצוגה רספונסיבית למחשב ולנייד.

## הפעלה מקומית
נדרשת התקנת Node.js:

```bash
npm install
npm run dev
```

## בנייה
```bash
npm run build
```

## פרסום
המאגר כולל הגדרות בסיסיות ל-Vercel. כדי לקבל כתובת ציבורית יש לייבא את המאגר לחשבון Vercel ולבצע Deploy. עדיין לא בוצעה פריסה ולכן אין כרגע כתובת אתר פעילה.

## שלבי הפיתוח הבאים
1. חיבור מנוע Stockfish אמיתי.
2. שעוני בליץ, ראפיד ובולט.
3. חשבונות משתמשים, פרופילים ודירוג ELO.
4. שרת ומשחקים מקוונים בזמן אמת.
5. שמירת משחקים, פאזלים וניתוח משחקים.
6. ממשק ניהול ואפליקציית Windows.

הגרסה הנוכחית היא אבטיפוס עובד של משחק מקומי, ולא מוצר מלא.
